## 이번 변경 검증

기존 72개와 NPC 검사 12개로 총 84개를 실행했습니다.

1. Actor 타입에 맞는 공식 NPC/캐릭터 클래스만 허용, 타사·잘못된 타입 제외.
2. NPC의 GM/OWNER/옵션 OBSERVER 허용, 권한 없음·LIMITED·컴펜디엄 제외.
3. NPC 준비된 HP·AC·우선권 수정치/수치·숙련·능력치·내성·기술·죽음 진행도와 원본 불변.
4. 인벤토리 무게·단위·화폐·조율·크기 데이터 재사용.
5. 무기 공격/특성/주문/소지품의 아이템 분류·권한·미식별 이름 보호.
6. 클릭한 이동 방식의 속도·단위·hover, 숨겨진 방식 거절.
7. 클래스 없는 NPC 주문 카드의 표시값과 0/미지정 능력 처리, Roll 재평가 없음.
8. 클래스 있는 NPC의 첫 클래스 연결·권한·능력 변경 검사.
9. 표시 숫자 부호/0 파싱, 입력란·수식·비정상 값 거절.
10. 단일 NPC 주문 카드와 숫자 속도 pill의 렌더 연결·이전 연결 제거.
11. 두 입력 모드의 동기적 차단과 관찰자 옵션 변경 후 실패 시 네이티브 동작 미실행.
12. 비연결 토큰의 합성 NPC Actor UUID, 공개 메시지, 한국어/영어 이름 이스케이프.

한국어·영어 26종 메시지와 모든 기존 지목 검사도 통과했습니다.
새 npc-browser.test.mjs와 npc-fixture.html에는 실제 DOM 선택자 기준 지원 대상 30개, 제외 대상 11개, 일반/Shift/Z 입력·관찰자 옵션·리스너 정리 검사를 작성했습니다.
`npm run test:npc-browser`를 실행했으나 Chromium 실행 파일 부재로 브라우저 실행 전에 종료했습니다. 따라서 실제 DOM 검사·시각 검증·FVTT 실행을 완료한 것으로 보고하지 않습니다.

## 실제 Foundry 확인 대기

| 항목 | 기대 결과 |
|---|---|
| NPC HP·AC·우선권·숙련·크기·능력치·내성·기술 | 실제 표시값과 일치, 이름 굵게, 굴림/편집 없음 |
| NPC 각 이동 방식·무기/특성/주문 이름·장비 pill | 선택한 방식/항목의 메시지 한 개, 공격/시전/소비 없음 |
| NPC 클래스 없음/있음·주문 능력/공격/DC | 시트 표시값과 일치, 클래스 연결 정확 |
| NPC 인벤토리 화폐·조율·무게·죽음 내성 | 해당 표시값·진행도, 입력/소비/굴림 없음 |
| NPC 소유자/관찰자/GM·LIMITED·GM 옵션 변경 | 기존 권한 정책 적용 |
| 업데이트 후 모든 브라우저 새로고침 | 0.4.0-alpha.1 로드, 이전 리스너 제거 |
| 빈 지도 지점의 휠 클릭 / Z + 좌클릭 | 채팅 1개, 실제 클릭 위치에 발신자 색상 핑, 카메라 자동 이동 없음 |
| `한 지점` 좌클릭 / 키보드 Enter | 저장 위치로 클릭한 사람의 화면만 이동, 확대 배율 유지 |
| 토큰 가장자리 지목 | 이름 링크와 토큰 중심의 원/화살표 핑 |
| 주문 카드 능력·공격·DC의 라벨·수치 | 해당 클래스/서브클래스 이름과 표시값, 캐릭터 이름 굵게 |
| 같은/다른 능력의 다중 클래스 | 선택한 카드와 수치 일치 |
| 주문 카드의 일반 클릭·대표 능력 선택·준비 개수 | 원래 동작 유지 |
| 관찰자 주문 카드와 GM 옵션 변경 | 열람/지목 권한 정책 적용 |
| 이동한 토큰의 채팅 이름 링크 | 현재 토큰 중심으로 이동 |
| 삭제·숨김·시야 밖 토큰의 링크 | 좌표 대체 없이 안내, 화면 이동 없음 |
| 다른 장면 링크 | 열람 가능하면 로컬 전환, 권한 없으면 안내, 다른 참가자의 장면 유지 |
| 여러 확대 배율·큰 토큰·비연결/NPC 토큰 | 정확한 위치, Actor 소유권 없이 보이는 토큰 지목 |
| 드래그·일반 클릭·Shift 조합·다른 레이어 | 기존 기능 유지, 의도하지 않은 지목 없음 |
| 시트 전체 지목·관찰자 옵션·수치 | 기존 문구/권한/스냅샷 유지, 굴림·소비·상태 변경 없음 |
| 장면 전환·채팅 재렌더 반복 | 입력·링크 리스너 중복 없음 |
| 두 계정·다른 토큰 조작 모듈 | 공개 채팅/핑 전달, 카메라 자동 끌기 없음, 이벤트 충돌 없음 |
| 밝은/어두운 테마·좁은 채팅 | 링크 구분·포커스·가독성·기본 관리 컨트롤 유지 |

공개 Foundry v13 문서의 표시는 13.350이며, 목표 13.351에서 실제 애니메이션·DOM·권한·장면 전환을 검증한 것은 아닙니다.
