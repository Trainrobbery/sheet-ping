# Sheet Ping — 0.4.0-alpha.2

**휠 클릭(가운데 버튼 누르기)**으로 캐릭터·NPC 시트의 항목이나 맵의 토큰·빈 지점을 전체 채팅에 지목합니다. 모듈 설정에서 **Z + 좌클릭**으로 바꿀 수 있습니다.

대상: **Foundry VTT 13.351 / D&D 5e 5.3.3 / 공식 기본 캐릭터·NPC 시트**.
이전 초안은 사용자로부터 작동 피드백을 받았습니다. 이번 버전 변경분의 실제 Foundry 검증은 아직 수행하지 않았습니다.

## 이번 업데이트

- 공식 **NPC 시트** 지목 지원을 추가했습니다. 기존 입력 방식(기본 휠 클릭 / 선택 Z + 좌클릭)을 사용합니다.
- NPC의 HP·AC·우선권 수정치/수치·숙련·크기·능력치·내성·기술·이동 속도, 공격/특성/주문 이름을 지목합니다.
- 클래스가 없는 NPC도 주문 시전 카드의 능력 수정치·공격 수정치·주문 내성 DC를 지목할 수 있습니다.
- 기존 GM/소유자/관찰자 권한 정책을 NPC 시트에도 적용합니다. 관찰자 지목 허용 옵션은 두 시트에 함께 적용됩니다.

## 설치·업데이트

FVTT 설정 화면 → **애드온 모듈 → 모듈 설치 → Manifest URL**에 다음 주소를 넣습니다.

```text
https://raw.githubusercontent.com/Trainrobbery/sheet-ping/main/module.json
```

설치 후 월드의 모듈 관리에서 Sheet Ping을 활성화합니다. 업데이트는 FVTT의 모듈 업데이트 버튼으로 확인합니다. 업데이트 후 모든 참가자의 브라우저를 새로고침합니다.

수동 설치는 [Releases](https://github.com/Trainrobbery/sheet-ping/releases)의 `sheet-ping.zip`을 내려받아 내부 파일을 `Data/modules/sheet-ping/`에 풉니다. `Data/modules/sheet-ping/module.json`이 있어야 합니다. 기존 폴더를 교체할 때는 Foundry를 종료한 뒤 교체하고 재시작합니다.

GitHub에서 자동 생성하는 소스 ZIP보다 릴리스에 첨부된 `sheet-ping.zip`을 사용합니다. 알파 릴리스는 GitHub의 latest 링크에 포함되지 않으므로 위의 고정 매니페스트 주소를 사용합니다.

기존 설정과 과거 채팅 메시지는 보존됩니다. 입력 방식의 기본값은 휠 클릭이며, 기존 입력 활성화 상태와 관찰자 옵션은 유지됩니다. 추가 모듈·서버·라이브러리는 필요하지 않습니다.

## 조작

- **기본값 — 휠 클릭:** Z 키 없이 마우스 휠을 눌러 지원 대상을 지목합니다. 휠을 굴리는 스크롤은 기존 동작입니다.
- **선택 옵션 — Z + 좌클릭:** 지목 입력 방식을 바꾸면 Z를 누른 채 좌클릭하여 지목합니다.
- 선택하지 않은 입력 방식은 지목하지 않습니다. 휠 클릭 모드에서 Z + 좌클릭은 기존 동작을 따릅니다.
- 지원 대상의 휠 클릭에서만 자동 스크롤·새 탭 열기 등의 브라우저 기본 동작을 막습니다.
- **일반 클릭 및 Shift + 클릭:** 시스템과 다른 모듈의 기존 동작.
- **Shift/Alt/Ctrl/Meta를 함께 누른 클릭:** 기존 동작. Sheet Ping은 가로채지 않습니다.
- 채팅·입력란에서 Z를 입력하는 동안에는 지목을 활성화하지 않습니다.
- 한글 자판에서도 같은 물리 키 `KeyZ`를 사용합니다. 창 포커스를 잃거나 입력란으로 이동하면 눌림 상태를 초기화합니다.
- 키보드 이벤트 자체는 취소하지 않으므로 기존 키보드 단축키는 그대로 처리됩니다.

| 주문 시전 능력 수정치 | 주문 탭 상단 클래스 카드의 능력 라벨·수치 | 클래스/서브클래스, 능력 이름과 수정치 |
| 주문 공격 수정치 | 같은 카드의 공격 라벨·수치 | 해당 클래스/서브클래스의 실제 공격 수정치 |
| 주문 내성 DC | 같은 카드의 주문 내성 DC 라벨·수치 | 해당 클래스/서브클래스의 실제 DC |

- **돈 관리 버튼 또는 화폐 영역의 빈 공간**을 선택한 방식으로 클릭하면 전체 화폐 잔액을 보냅니다. 자동 환산하지 않으며 0인 잔액도 표시합니다.
- 돈의 숫자 입력란은 편집용으로 유지합니다. **입력란이 아닌 화폐 아이콘**을 클릭합니다.
- 고양감을 지목해도 보유 상태가 바뀌지 않습니다. 관찰자 시트의 고양감 버튼이 비활성화되면 옆에 지목용 상태 텍스트를 표시합니다.
- HP 일반 클릭은 기존 조정 기능입니다. HP 지목은 임시 HP를 합산하지 않으며, 최대치 증감 효과를 반영한 시트의 유효 최대치를 사용합니다.
- 지목 값은 저장된 문서 기준이며 저장 전 입력값은 읽지 않습니다.
- 설정·장착·준비·숙련 토글·삭제·활동·일반 아이템 이미지·설명은 지목하지 않습니다. 고양감·돈 관리·탈진 점·죽음 내성 표시와 상단 용기 아이콘은 명시적으로 지원합니다.
- 무게는 시스템의 현재 무게 단위(lb/kg 등)를 사용합니다. 크기 보정률은 근력·크기에서 재계산하지 않고 보너스와 효과가 반영된 시트 값을 읽습니다.
- 조율의 최대치 입력란은 편집용입니다. 탈진·죽음 내성의 비활성화된 버튼 옆에는 관찰자용 지목 텍스트를 표시합니다.
- 주문 시전 카드의 대표 능력 선택 버튼·제목·준비 개수는 지목 대상이 아닙니다. 능력/공격/DC의 이름 또는 수치를 선택한 방식으로 클릭합니다. 시전·굴림·슬롯 사용·대표 능력 변경을 실행하지 않습니다.

예시:

- `● 민수님이 아르벨의 고양감 있음 지목`
- `● 민수님이 아르벨의 보유 금액 120 금화 지목`
- `● 민수님이 아르벨의 HP가 22/50라고 지목`
- `● 민수님이 아르벨의 위저드 주문 시전 능력(지능) 수정치 +4 지목`
- `● 민수님이 아르벨의 위저드 주문 공격 수정치 +9 지목`
- `● 민수님이 아르벨의 위저드 주문 내성 DC 18 지목`

## NPC 시트

공식 기본 NPC 시트의 표시된 이름·수치를 선택한 입력 방식으로 클릭합니다.

| 대상 | 클릭할 위치 | 내용 |
|---|---|---|
| HP / AC | 상단 HP 표시·막대 / AC 수치 | 현재/유효 최대 HP / 방어도 |
| 우선권 | 초상화의 수정치 / 별도의 우선권 수치 | 수정치 또는 수치로 구분 |
| 숙련 / 크기 | 상단 숙련 글자·숫자 / 크기 글자 | 숙련 보너스 / 크기 |
| 능력치 / 내성 | 능력 약칭·점수·수정치 / 아래 방패·내성 수치 | 능력 점수·수정치 / 내성 수정치 |
| 기술 | 왼쪽 기술 목록의 이름·수치 | 기술 총수정치 |
| 이동 속도 | 왼쪽 이동 방식의 이름·수치 | 클릭한 방식의 속도와 단위 |
| 공격 / 특성 / 주문 | 각 목록의 제목 글자 | 무기 공격·특성·주문 이름 |
| 장비 | 왼쪽 장비 이름 | 해당 아이템 이름 |
| 주문 시전 | 주문 탭 위 카드의 능력·공격·DC 이름/수치 | 시트에 표시된 값 |
| 돈 / 무게 / 조율 | 인벤토리 화폐 아이콘·무게 막대·조율 표시 | 잔액 / 현재·최대 무게 / 조율 사용·최대 |
| 죽음 내성 | 표시 중인 죽음 내성 버튼·성공/실패 아이콘 | 성공/실패 진행도 |

- NPC 이동 속도는 클릭한 방식(보행/비행 등)을 표시합니다. 자유 서술형 특수 이동 문구는 수치 지목 대상이 아닙니다.
- NPC 주문 카드는 실제 렌더된 숫자 텍스트를 읽어 저장합니다. NPC의 첫 주문 시전 클래스 또는 기본 주문 능력과의 연결을 확인하며, 지목 시 보너스 수식이나 주사위를 다시 계산하지 않습니다.
- NPC가 클래스를 보유하면 주문 시전 문구에 그 클래스 이름을 포함합니다. 클래스가 없으면 NPC 이름과 주문 시전 수치를 표시합니다.
- NPC 이름도 굵게 표시합니다. 공격 이름 지목은 공격 굴림·피해·슬롯/횟수 소비를 실행하지 않습니다.
- 숫자 입력란·설정 버튼·숙련 토글·전설적 행동 점·기타 편집 컨트롤은 기존 동작입니다. 수치가 표시되는 플레이 모드의 이름/표시값을 지목합니다.
- 시트 열람과 지목은 GM/소유자 또는 옵션이 허용한 OBSERVER 권한이 필요합니다. NPC의 토큰이 보인다는 이유만으로 NPC 시트의 데이터를 공개하지 않습니다.

## 맵의 토큰과 빈 지점

토큰 선택 레이어에서 보이는 토큰 위에 마우스를 놓고 **휠 클릭**합니다. Z + 좌클릭 모드를 선택한 경우에는 Z를 누른 채 좌클릭합니다.

예: `● 민수님이 고블린 A 지목`

- 연결된 캐릭터 이름 대신 **토큰 문서의 이름**을 사용합니다.
- Actor 열람·소유 권한 없이도 현재 보이는 토큰의 이름을 지목할 수 있습니다. NPC 토큰도 포함합니다.
- 선택·이동·공격 대상 지정을 실행하지 않고 채팅과 지도 핑 효과만 표시합니다.
- 토큰의 중심에 Shift 길게 클릭의 원·아래쪽 화살표(chevron) 모양을 표시합니다. 핑 색상은 해당 플레이어 색상이며 화면 이동은 끕니다. 같은 장면에 접속한 다른 참가자에게도 기본 FVTT 핑 전달 경로로 표시합니다.
- 채팅 전송에 실패하면 지도 효과도 보내지 않습니다. 효과만 실패하면 채팅을 다시 보내지 않고 별도 알림을 표시합니다.
- 빈 지도 지점에서는 토큰 이름 대신 `● 민수님이 지도의 한 지점을 지목` 메시지와 실제 클릭 위치의 핑을 표시합니다. 다른 레이어에서는 동작하지 않습니다. 보이지 않는 토큰의 이름은 읽지 않습니다.
- 마우스를 누른 채 6px 넘게 움직이거나, 입력 방식을 바꾸거나, 창 포커스를 잃으면 토큰 지목을 취소합니다. Z 모드에서는 떼기 전에 Z를 놓아도 취소합니다.
- 현재 시점의 토큰 이름을 저장하므로 나중에 이름 변경·삭제가 있어도 과거 메시지의 문구는 유지됩니다.
- 새 메시지의 **토큰 이름** 또는 **한 지점**은 밑줄이 있는 링크입니다. 마우스를 올리면 위치 이동 안내를 표시합니다. 일반 좌클릭 또는 키보드 Enter로 해당 위치로 이동합니다.
- 지점 링크는 저장된 Scene 좌표, 토큰 링크는 현재 보이는 토큰의 중심을 사용합니다. 토큰 링크는 삭제·숨김·시야 변경 후 옛 좌표로 대체하지 않고 안내를 표시합니다.
- 다른 장면의 링크는 열람 가능한 장면을 클릭한 사람에게만 열어줍니다. 장면 활성화·다른 참가자의 화면 이동·토큰 선택은 하지 않습니다. 권한이 없는 장면은 안내를 표시합니다.
- 새 지목의 링크만 적용하며 이전 채팅 내용을 일괄 수정하지 않습니다.

## 관찰자와 설정

게임 설정 → 모듈 설정 → Sheet Ping:

| 설정 | 범위 | 기본값 |
|---|---|---|
| Sheet Ping 사용 | GM이 관리하는 월드 | 켬 |
| 지목 입력 사용 | 각 클라이언트 | 켬 |
| 지목 입력 방식 | 각 클라이언트 | **휠 클릭** |
| 관찰자 지목 허용 | GM이 관리하는 월드 | 켬 |

**지목 입력 방식**에서 `휠 클릭 (가운데 버튼)` 또는 `Z + 좌클릭`을 선택합니다. 열린 시트와 맵에도 즉시 반영됩니다.

관찰자 허용 시 **OBSERVER 이상** 권한의 캐릭터·NPC 시트에서 지목할 수 있습니다.
GM이 끄면 시트 지목은 소유자와 GM에게만 허용됩니다. LIMITED 또는 권한 없음은 허용하지 않습니다.
옵션 변경은 다음 지목부터 적용됩니다. 문서 편집·열람 권한 자체를 바꾸지 않습니다.
이 옵션은 **시트 정보 지목**을 제한합니다. 맵의 보이는 토큰과 빈 지점 지목은 별도로 유지됩니다.

## 메시지와 데이터

- 모든 새 시트 지목에서 **캐릭터 이름을 굵게** 표시합니다. 기존 채팅 기록을 다시 쓰지는 않습니다.
- 새 지목 메시지는 플레이어 이름 앞에 **●**를 표시합니다. 기호만 해당 사용자의 FVTT 지정 색상을 사용하며 이름·본문 색상은 그대로입니다.
- 색상은 전송 시점에 저장하므로 사용자 색상을 바꿔도 과거 메시지는 바뀌지 않습니다. 이전 버전에서 작성한 메시지는 수정하지 않습니다.
- 불투명한 배경을 사용하며 밝은/어두운 테마에서 글자 대비를 조정합니다.
- 별도 상시 헤더·초상화를 숨깁니다. hover/focus 시 기본 시간·관리 컨트롤을 표시합니다.
- 일반 채팅과 굴림 메시지의 스타일은 바꾸지 않습니다.
- 모든 지목은 **전체 공개**이며 보낸 사람의 언어로 작성한 동일 문장을 저장합니다.
- Actor/Item/Token을 수정하거나, 주사위 굴림·고양감 소비·화폐 변경·문서 권한 변경을 하지 않습니다.
- 미식별 아이템은 GM도 공개용 이름을 사용합니다. 설명·비밀 내부 이름은 복사하지 않습니다.
- `flags.sheet-ping.snapshot`에는 해당 지목의 최소 데이터만 저장합니다. 토큰 지목에는 Actor 데이터를 포함하지 않습니다.
- 아이템 링크와 문서 자동 공개는 아직 구현하지 않았습니다.

## 개발·검증

```bash
npm test
npm run test:browser
npm run test:npc-browser
python3 tools/package.py
python3 tools/package.py --release
```

단위 검증은 Node 22 이상에서 외부 패키지 없이 실행합니다.
브라우저 검증은 Playwright와 Chromium이 필요합니다. 개발 환경에서 필요하면 `npm install --no-save playwright`, `npx playwright install chromium`을 실행합니다. Foundry 이용자에게는 필요하지 않습니다.

- `scripts/keyboard.mjs`: Z 키 상태·포커스·입력란 처리
- `scripts/input.mjs`, `targets.mjs`: 시트 대상과 캡처 리스너
- `scripts/token.mjs`: 보이는 토큰·빈 지점 식별, 포인터 동작, 지도 핑
- `scripts/navigation.mjs`: 채팅 링크와 로컬 화면 이동·장면 권한 확인
- `scripts/npc-targets.mjs`: NPC 헤더·목록·주문 카드의 지목 대상
- `scripts/dnd5e.mjs`: 권한·시스템 데이터·스냅샷
- `scripts/chat.mjs`, `formatter.mjs`: 공개 채팅과 문장·이스케이프
- `tests/`: 단위·DOM 테스트
- `docs/TEST-REPORT.md`: 실제 실행 결과와 수동 검증 목록
- `docs/IMPLEMENTATION.md`: 공식 소스와 구현 근거

지원 범위는 지정 버전과 공식 기본 캐릭터·NPC 시트로 제한합니다. Tidy·레거시·다른 시트, 차량·그룹 시트, 즐겨찾기·활동은 제외합니다.
다른 모듈이 더 앞선 이벤트에서 행동을 실행하면 차단을 보장할 수 없습니다. 실제 굴림·토큰 조작 모듈 조합에서 확인이 필요합니다.
소스 저장소: [Trainrobbery/sheet-ping](https://github.com/Trainrobbery/sheet-ping). 라이선스는 아직 확정하지 않았으며, 매니페스트 `verified`는 실제 플레이 검증 전에는 선언하지 않습니다.

## 릴리스 게시

`module.json`, `package.json`의 버전과 버전별 download 주소, 변경 기록을 갱신하고 main에 커밋하면 Publish Sheet Ping 작업이 실행됩니다. 작업은 자동 검증 후 설치 ZIP과 module.json을 초안 릴리스에 업로드하고 게시합니다. 게시한 버전을 덮어쓰지 않으므로 이후에는 버전을 올립니다.

`manifest`는 고정된 main의 raw module.json, `download`는 버전 태그에 고정된 설치 ZIP입니다. 알파 버전은 GitHub prerelease로 표시하며, FVTT 설치는 위 매니페스트 URL로 가능합니다.
